# Versão 2.17 — Plano de execução

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** escritório em kg (cal 680 g/copo, uréia 780 g/caneca), nível pela pessoa com aparelho fixo, PC com entrada por nome e painel ao vivo, logo do U com abertura animada e notificações com ×.

**Architecture:** scripts comuns em `public/` (sem import; `index.html` dá a ordem), duas centrais iguais (`server.js` e `ServidorCentral.java`) e a nuvem (`nuvem/src/index.js`, Worker + D1). Regra de soma numa fonte só (`C.somarEm`); a nuvem recebe da central só o que o PC precisa ver.

**Tech Stack:** JavaScript puro, Node (central e testes), Java (central do tablet), Cloudflare Worker + D1, Electron (PC), Chrome sem janela nos testes.

**Spec:** `docs/superpowers/specs/2026-10-25-versao-2-17-design.md`
